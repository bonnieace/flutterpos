Why the top of page 1 carries the day

WhatsApp shows the first page of a PDF as a thumbnail, cropped to its top. So the masthead, the date, the total and the open-shift warning all sit in the top third of page 1, and the total is set large enough to read at this size without opening the file.

The message text repeats the same figures, so the report is useful even before the PDF is downloaded.

“Sender name” is whatever display name the shared WhatsApp number carries; the report does not set it.
