Report pills

A new component. AppTabs is a Material TabBar with a travelling underline — a different control for a different job, and it stays where it is on the platform console. This is a filled segmented control, and hard rule 5 means it ships with every state it can be in.

Each pill opens its own report. It is not a filter over a shared dashboard: Day, Week and Month have different cards, different reads and different downloads. That is why they are pills and not a period selector.

Resting strip, at 390

Scrolls horizontally. The selected pill is scrolled into view on open, so a report five along is never off-screen when it is the one showing.

Why 48 and not 40

Hard rule 4 is pass/fail on a 48×48 target. The reference these are drawn from uses roughly 40, which fails it. AppTabs already carries this fix in a comment: a Material text tab is 46 logical pixels and had been two short since it was written. These start at 48 rather than being corrected to it later.

What the component owns, and what it must not

OwnsNote
selectedIndexRead from the parent. The strip does not hold which report is showing — a component that owned that would be a behaviour change wearing a visual component’s clothes, which is the argument ui/tabs.dart already makes for not creating its own controller.
onSelectedThe parent decides what a selection costs. Which matters here: Day is free, Week is nine callables.
Scroll-into-viewOn mount and on selection change.
KeyboardArrow keys move between pills, Home and End to the ends, Enter or Space selects — the tablist contract.
Must not: loadThe strip never triggers a read. The report body behind it is built lazily on first selection and kept alive after, or switching back to Week pays the nine callables twice.

One thing worth knowing

There is a retired decision in this repo against pills — OPEN_QUESTIONS.md decision 19, quoted in test/dev/reachable_lib_test.dart, alongside three unreachable pill widgets in lib/widgets/. Per CLAUDE.md that document is reference and not authority, and this is your call. It is named here only so nobody re-opens it as though it were settled the other way. The unreachable pill_button.dart is not a starting point: it predates the token layer and carries its own colours.
