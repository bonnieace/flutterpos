Tables

One table component, the sheet, for every screen that today stretches phone cards across a large window. It is quiet: monochrome rows, figures in a right-aligned column, and status drawn only where something wants attention. It is fitted to a till: mono figures with a unit stated once, day breaks, folded receipt lines, and a mint total. It is drawn on the screens the audit named, except the platform console. Read README.md for the reasoning, the departures, what is not a pure restyle, and the open questions.
