Icon tabs, scrolling

Configs on a 320 phone. With their glyphs, the four tabs need 494. Each end with more tabs past it fades over 32 (space.32). The fade is a mask, so it works on any ground.

Motion

Each shape has one moving part. The switch’s thumb slides as one piece on spring.snappy (380 / 32), because both halves are the same width. The icon tabs’ underline stretches: the end it is travelling towards leads on spring.snappy, and the other end follows on spring.smooth (220 / 30), because the tabs are different widths. Pressing again mid-move retargets from where the part is, at the speed it is going.

  • A swipe on a page still drives the moving part directly. While a finger drags TabBarView, the thumb or underline follows the controller’s offset with no spring, so it never lags the finger. The springs take over on a tap, and on release they start from the speed the drag left them with.
  • Labels keep following the controller. Their colour cross-fades with TabController’s own animation, as it does now.
  • Neither spring visibly overshoots. spring.bouncy is not used: an operational control that wobbled would read as unstable.
  • Under disableAnimations both parts jump to their new place in one frame, which SpringDrive already does.
